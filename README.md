# Hey there, I'm Julian Agudelo 👋

🌍 Colombia 🇨🇴 | I like turning real-world problems into simple, efficient tools

**Full-Stack Developer | JavaScript & Node.js | Express, MongoDB & Firebase | AI-assisted development**

I'm a full-stack developer who enjoys building software that solves concrete, everyday problems. I like taking an idea from a blank page to a working product: modeling the data, building the backend, and shaping an interface that people can actually use.

My work so far is centered on JavaScript and Node.js. On the backend I build REST APIs with Express and choose the storage that fits each problem, from MongoDB for flexible documents to SQLite for lightweight structured data and Firebase for cloud sync. On the frontend I favor lean, framework-free code: fast to load, easy to maintain, and installable as a PWA with offline support.

I'm especially interested in domain-heavy software, where getting the rules right matters. I like validating my work against real-world data, and I care about privacy: some of my tools run fully offline and never store anything on a server.

I also use AI tools like Claude Code in my daily workflow to prototype faster, review my own code, and learn new technologies, while keeping design decisions and testing in my own hands.

Outside of work, I enjoy building personal projects, experimenting with new ideas, and turning concepts into products with real-world impact.

## 🚀 Featured Projects

- **[Declaración de Renta (Colombia)](https://github.com/jsowl044/declaracion-renta)** — Calculator for the Colombian personal income tax return (DIAN Formulario 210). Imports the DIAN *exógena* report, works 100% offline without storing anything, and exports the result to Excel. Validated field by field against real filed returns.
- **[Flashcards PWA](https://github.com/jsowl044/flashCards)** — Installable study app with spaced-repetition queues, deck import/export, offline support through a Service Worker, and optional cloud sync with Firebase (Google sign-in + Firestore).
- **[Product Catalog App](https://github.com/jsowl044/taller-catalogo-productos)** — Full-stack catalog with Express, MongoDB and SQLite (polyglot persistence), image uploads and a sale/promotion flag.
- **[Minesweeper](https://github.com/jsowl044/Minesweeper)** — Multiplayer Minesweeper with real-time play over WebSockets and a Node.js game server.
